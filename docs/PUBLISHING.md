# 本地 Git 与发布准备

本仓库初始化于 `main`，初始提交只含最终生产源码、文档和可移植测试。旧项目、历史脚本、备份、原始测试记录及用户游戏数据留在本地原位置；没有伪造历史提交。

本地候选标签为 `v0.2.5-rc.1`，表示 0.2.5 的候选稳定快照，不是已发布 Release，也不改变脚本显示的 0.2.5。没有配置远程仓库、创建 GitHub 仓库、Push、发布 Release 或设置 Public。

初始提交 / 标签使用 `MML local preparation <mml-local@localhost>` 作为中性的本地准备标记，避免泄露个人全局 Git 邮箱；这不是实际维护者或 GitHub 账号。公开前请决定署名及未来贡献的 Git 身份。没有修改全局 Git 配置。

## 所有者仍需决定

1. MIT / Apache-2.0 / GPL-3.0 的选择、版权署名和授权权利。确认后才能加入 LICENSE 并将项目描述为已开源授权。
2. [安全审查](SECURITY-REVIEW.md) 中的 S1 是否在公开前修复，及其他已说明边界是否接受。
3. 是否补做真实 Minecraft 启动、干净 Windows 与其他 PS7 版本验收，再将候选状态转为最终稳定发布。
4. GitHub 所有者、仓库名、可见性、提交署名及是否允许创建远程仓库 / Push / Release。每项发布动作仍需明确授权。

## 维护约定

0.2.5 是 0.2 系列最后的功能版本，仅计划修复 Bug 和严重安全问题。修改 C# 后在新进程分别运行 PS5.1 / PS7 测试，保留 `%LOCALAPPDATA%\MML0.2` 数据兼容；更新 CHANGELOG 和测试证据，避免将受控测试写成真实游戏启动成功。

问题报告应包含 PowerShell 版本、所选 Minecraft / Java 版本、复现步骤与已脱敏的错误。不要提交完整个人缓存、凭据、游戏文件或原始日志。未来确认 GitHub 地址后再加入有效的问题反馈链接；当前不伪造仓库地址或安全联络邮箱。
